# WhatsApp broadcasts

A broadcast sends one Meta-approved WhatsApp template to a contact list, segment, or set of contacts. Messages go out in daily batches between a start date and an end date.

Every broadcast goes through the same five steps. Each step lives in its own sidebar menu.

| Step | Where | Guide |
| --- | --- | --- |
| 1. Connect a WhatsApp number | **Channels** | [Connect a WhatsApp channel](broadcasts/connect-channel.md) |
| 2. Create a template and get it approved by Meta | **Templates** | [Create a template](broadcasts/create-template.md) · [Template guidelines](broadcasts/template-guidelines.md) |
| 3. Prepare the audience | **Audience** | Import contacts, or build a list or segment |
| 4. Create, test, and publish the broadcast | **Broadcast** | [Send a broadcast](broadcasts/send-broadcast.md) · [Broadcast guidelines](broadcasts/broadcast-guidelines.md) |
| 5. Track results and fix failures | **Broadcast** → open a broadcast | [Results and errors](broadcasts/results-and-errors.md) |

Before every send, run the [pre-send checklist](broadcasts/checklist-faq.md).

The **Quick create** drawer has shortcuts for Broadcast, Template, Contact list, and Segment. The create pages have a **Watch a demo** button.

> [!NOTE]
> Only templates with the status **Approved** can be broadcast, and only from a **Connected** channel. Meta's rules behind these guides are linked in [Meta sources](broadcasts/meta-sources.md).
