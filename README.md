# Welcome to FlowFlex

FlowFlex helps businesses talk to customers on **WhatsApp**: send broadcasts to many contacts, automate replies and customer journeys with flows, and trigger messages from your own systems.

New to FlowFlex? Start with [Set up your account](getting-started.md).

## What do you want to do?

| Import my contacts or build a segment | [Import and export](audience/import-export.md) · [Segments](audience/segments.md) |
