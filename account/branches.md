# Branches

A branch is a separate workspace inside your organisation, such as one store or one city. Rangoli Store, for example, runs a **Bengaluru** branch and a **Kochi** branch.

## What a branch keeps separate

Each branch has its own:

- WhatsApp channels, and the templates of each channel's WhatsApp Business Account;
- broadcasts;
- flows and campaigns;
- audience: contacts, lists, segments, custom fields, imports, and exports;
- tags;
- conversations and custom chat folders;
- integrations.

Users see a branch only if their access includes it. See [Teams](account/teams.md).

## Manage branches

Go to **Settings** → **Branches**. Only Admins see this page in the sidebar.

<img src="assets/account/branches.png" alt="Settings, Branches">

| Column | Values |
| --- | --- |
| Logo | Branch logo |
| Name | Branch name |
| Location | Address from **Branch location** |
| Status | **Active** or **Disabled by Plan** |
| Action | Edit |

Use **Search by name** to find a branch.

## Create a branch

1. Click **Create branch**. FlowFlex checks your plan's branch limit first.
2. Optional: upload a logo. JPG or PNG, under 5 MB.
3. Enter **Branch name**. It must be at least 3 characters.
4. Optional: start typing an address in **Branch location** and pick a suggestion.
5. Click **Create branch**.

You see **Branch created successfully!**

## Edit a branch

1. Click the edit icon on the branch row.
2. Change the logo, **Branch name**, or **Branch location**.
3. Click **Update branch**. If nothing changed, you see **No changes detected**.

## Branch limits

| Message | Cause | Fix |
| --- | --- | --- |
| **Branch limit reached. You can purchase additional branches for … each in Billing.** | You use all branches in your plan plus add-ons | Add **Additional Branches** on [Plans](account/plans-and-add-ons.md). FlowFlex opens **Plans** for you. |
| **Branch limit reached. Please upgrade your plan to add more branches.** | Your plan has no branch add-on | Upgrade on [Plans](account/plans-and-add-ons.md) |
| **Disabled by Plan** | You have more branches than your plan allows, for example after a downgrade | Hover the status to see why. Add branches back to your plan to re-enable it. |

You cannot edit or switch to a branch that is **Disabled by Plan**. Trying shows **Cannot edit branch.** with the reason.

## Switch branch

1. Click your name and branch at the top right.
2. Choose **Switch branch**.
3. In **My Branches**, click a branch. The active branch is marked **Active**.

Click **Manage** in **My Branches** to open **Settings** → **Branches**.

> [!TIP]
> The branch name under your name shows where you are. Check it before you create a template or send a broadcast.
