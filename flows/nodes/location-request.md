# Location request

> Ask the customer to share their location on WhatsApp.

Set **Destination number** and **Message**, such as “Share your location so we can find your nearest store.”

Enable **Wait for specific time** and choose a unit and value to capture a response. Connect **Next step** for a reply and **No response** for the timeout. Use the captured location through **Insert Variable** in later steps, for example Calculate distance.

See [Waiting for a reply](flows/response-wait.md). To send a known location, use [Send location](flows/nodes/send-location.md).
