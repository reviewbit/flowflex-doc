# Link button

> Send a WhatsApp message with a button that opens a URL.

Set **Destination number**, **Message**, **Button label** (for example “View order”), and **Button URL**. The URL accepts variables for personalized links. **Footer** is optional.

Connect **Next step** to another action or End. Opening a URL does not expose a per-click reply branch. Use [Button message](flows/nodes/button-message.md) to branch on a reply button.
